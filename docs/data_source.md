# 数据来源

> 面试第一句常是「数据哪来的」。答「网上下载的」会立刻把作品降级成课程作业。
> 这份文件就是为了让这个问题有一份能指着念的答案。

## 1. 六项基本信息

| 项 | 内容 |
|---|---|
| **源头** | 中国环境监测总站（CNEMC）全国城市 / 站点空气质量实时发布平台 |
| **整理方** | quotsoft.net（个人整理站点，作者王晓磊），把总站的逐小时发布整理成按日打包的 CSV |
| **快照日期** | 2026-10-24（取数时主页标记为「更新到 2026.10.24」） |
| **获取方式** | 年度 zip 打包，逐年下载；每个 zip 内是按日的 CSV（`YYYYMMDD.csv`） |
| **本窗口规模** | 城市级 2021–2025 共 5 个年度包，解出 **1,826 个日文件** |
| **许可与引用** | 原始数据为政府公开环境监测数据；引用时注明「数据来源：中国环境监测总站，经 quotsoft.net 整理」 |

> ⚠️ 本仓库**不包含原始数据**（`data/raw/` 已在 `.gitignore` 里）——
> 体积太大，且原始数据的版权不属于本项目。要复现请按第 4 节自行下载。

## 2. 文件形态（真正的难点在这里）

原始日文件**不是**「一行一条记录」的规整表：

```
378 列 = 3 个标识列（date, hour, type） + 375 个城市列
360 行 = 24 个小时 × 15 种指标
```

也就是说 **城市在列、时间在行、指标也在行**。要变成一张能查询的事实表，
必须走三步：

1. **`melt`**：宽表拍扁成长表（城市名从列名变成一列的值）
2. **`pivot`**：按小时把 `PM2.5` / `PM2.5_24h` / `AQI` … 15 种指标转成 15 列
3. **按日聚合**：一城一天一行（`AQI`、`*_24h` 取当日值，小时类指标取日均）

这三步里的坑（列序、列名重复、`_24h` 被误当小时值、缺失被填 0 等）记在
[`README.md` §8 踩坑记录](../README.md) 与 `docs/troubleshooting.md`。

## 3. 几个必须先知道的坑

| 现象 | 原因 |
|---|---|
| `375 个城市列`，但成品表只有 372 城 | `甘孜州` / `那曲` / `黔东南州` 三列**全空**，同城另有全名列（`甘孜藏族自治州` / `那曲地区` / `黔东南苗族侗族自治州`），空列被自然丢弃 |
| 同时存在 `PM2.5` 与 `PM2.5_24h` | 前者是当小时浓度，后者是发布方给的 24 小时滑动均值；**不能互相替代** |
| `O3_24h` 大量缺失 | 2024 年整年未发布，2025 年只发了约 13%（详见 `reports/report.md` §10） |
| 站点级编号是 `1001A` 这种 | 是监测点位编码，不是城市名；需要站点列表才能映射到城市 |
| 2024 年是 366 天 | 闰年；跨年比较时要按天数归一 |

## 4. 自己复现

```bash
# 1) 从 quotsoft.net 下载年度 zip，放到 data/raw/city/
#    （本窗口：city_20210101-20211231.zip … city_20250101-20251231.zip）
# 2) 跑流水线
python scripts/prepare_data.py --no-resume
# 3) 出报告
python scripts/make_report.py
```

`data/raw` 的目录约定与年份窗口见 `src/config.py` 里的 `DEFAULT_YEARS`。

## 6. 为什么没做「更细粒度」

本机其实**有** 13 个站点级年度包（约 2.4 GB），但最终选了城市级。理由是主动取舍，不是偷懒：

| 维度 | 城市级 | 站点级 |
|---|---|---|
| 标识 | 自带城市名 | `1001A` 这类点位编码 |
| 长周期可比 | 5 年直接对齐 | 2016-11 之前没有官方站点列表，无法稳定映射 |
| 数据量 | 632,513 行 | 约 4.6 倍 |
| 结论口径 | 「这座城市的空气」 | 「这个监测点附近」 |

面试时的一句话版本：

> 城市级和站点级的差别我实测过：站点级列名是 `1001A` 这种编号，
> 且 2016-11 之前没有官方站点列表做映射；城市级自带城市名、数据量小 4.6 倍、长周期可比。
> 我选择牺牲粒度换可比性——如果要做「城区 vs 郊区」，那是另一个问题，得换数据源。

站点级路径**不是没实现**：`AQI_DATA_LEVEL=site python scripts/prepare_data.py`
可以跑（2026-11-23 用 3 个日文件验证过，5,297 行 × 25 列、站点覆盖率 0.9989），
只是没跑全量。
